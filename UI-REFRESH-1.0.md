# VolleyCore UI Refresh 1.0

## Visual direction
- Club core: red, black, white.
- Sports accent: turquoise/celeste inspired by the alternate Santa Bárbara uniform.
- Red = primary actions / club identity.
- Black = navigation / premium contrast.
- Turquoise = training, attendance, sports-data accents.
- Green/amber/red remain functional status colors.

## This version changes presentation only
- Modern desktop sidebar.
- Tablet/mobile responsive navigation.
- Modern cards, KPI tiles, tables, dialogs and forms.
- Updated login presentation.
- Dark mode toggle persisted in localStorage.
- Dashboard hero treatment.
- Subtle transitions and hover states.

## Business logic intentionally unchanged
Firebase, Firestore, roles, payments, attendance, families, categories, events,
trainers and reporting logic remain based on Stable 3.4.2.
