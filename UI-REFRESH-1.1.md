# VolleyCore UI Refresh 1.1 — Dashboard Redesign

This version implements the approved dashboard direction using the real VolleyCore data model.

## Visual
- Official Santa Bárbara shield extracted from the user-provided club artwork.
- Santa Bárbara / La Gran Familia / ASBAVOL header lockup.
- Black grouped sidebar inspired by the approved mockup.
- Red, white, black and turquoise sports palette.
- Responsive dashboard for desktop, tablet and mobile.

## Dashboard uses live data
- Active players.
- Pending monthly charges.
- Players currently overdue.
- Attendance average.
- Next recurring training.
- Next scheduled match.
- Upcoming events.
- Recent payment / attendance / player activity.
- Recent pending payments.

## Quick actions
- New player.
- Payments.
- New event.
- Reports.
- Direct KPI navigation.

## Business logic
No Firestore rules or underlying finance/family/attendance logic was changed.
