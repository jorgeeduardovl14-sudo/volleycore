# VolleyCore Roadmap

## Sprint 1 - Families and player profiles

### 1. Family domain

- Correct dashboard family count.
- Show users and players inside each family.
- Add an existing player to a family.
- Merge duplicate families.
- Preserve historical links.

### 2. Player profiles

- Open each linked player independently.
- Display all active categories.
- Show training schedules by category.
- Show upcoming events by category.
- Show fees only to authorized guardian accounts.

### 3. Multiple categories

- Replace the single-category selector with multiple selection.
- Keep a primary category.
- Maintain compatibility with existing player records.

### 4. Real-time behavior

- Link requests update without refresh.
- Approved links update the family portal without refresh.
- Linked players update without refresh.

## Sprint 2 - Calendars and schedules

- Category calendars.
- Excel and CSV import.
- External calendar links.
- Weekly training summaries.
- Event history.

## Sprint 3 - Treasury

- Monthly charges.
- Manual status management.
- Payment history.
- SINPE review.
- Financial dashboard.
